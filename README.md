# Patch Tuesday Readiness Toolkit

A read-only PowerShell toolkit for monthly Windows patch readiness checks.

## Features

- OS build context
- Free disk space check
- Pending reboot indicator
- Windows Update service context
- Latest installed hotfix summary
- CSV, JSON, and HTML reports

## How to run

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\Patch_Tuesday_Readiness_Toolkit.ps1
```

## Safety

Diagnostic-only. It reports patch readiness context for support review.
